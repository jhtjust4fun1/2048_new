# 2048 爆炸版：金币系统与格子皮肤商店设计文档

## 一、 需求概述

为了丰富游戏玩法与长期激励机制，项目新增**金币系统**与**格子皮肤商店**功能：
1. **难度积分换算金币**：玩家在“简单”、“中等”、“困难”、“噩梦” 4 个难度下获得的分数，按不同比例换算为金币。
2. **格子皮肤商店**：玩家消耗获得的金币购买不同的格子主题皮肤，并可随时切换已解锁的皮肤。
3. **皮肤配置化**：所有皮肤样式（主题配色、名称、价格、解锁状态等）采用结构化配置，便于后期扩展与维护。

---

## 二、 金币系统设计

### 1. 换算规则与难度系数

游戏过程中合并方块或爆炸清场获得的分数，在游戏进行中/结算时按以下比例自动转化为玩家的金币：

| 难度等级 | 换算比例 (分数 : 金币) | 说明 |
| :--- | :--- | :--- |
| **简单 (Easy)** | 100 分 = 1 金币 | 较轻松，金币转化率基础 |
| **中等 (Normal)** | 50 分 = 1 金币 | 标准难度，2x 收益 |
| **困难 (Hard)** | 25 分 = 1 金币 | 挑战较高，4x 收益 |
| **噩梦 (Nightmare)** | 10 分 = 1 金币 | 极高挑战，10x 收益 |

### 2. 金币获取与结算逻辑
* **实时/结算增加**：玩家在游戏中得分时累加待结算分数，按相应难度的系数计算并增加玩家账户的总金币数。
* **持久化存储**：金币数据存储在 `sys.localStorage` 中，本地 Key 定义为：
  - `2048_total_coins`: 存储玩家当前拥有的总金币数。

## 三、 格子皮肤商店设计

### 1. 皮肤可配置化结构 (`SkinConfig`)

在 TypeScript 中定义皮肤配置模型，支持扩展更多皮肤：

```typescript
export interface TileColorConfig {
    bg: string;   // 方块背景色 (HEX 或 Color 字符串)
    text: string; // 文字颜色
}

export interface SkinConfig {
    id: string;                    // 皮肤唯一标识 (如 'classic', 'neon', 'dark', 'macaron')
    name: string;                  // 皮肤显示名称
    price: number;                 // 购买价格 (金币)
    description: string;           // 皮肤描述
    colors: TileColorConfig[];     // 方块数值配色方案表 (对应 2, 4, 8, 16 ... 4096+)
    boardBg?: string;              // 棋盘背景色 (可选)
    cellBg?: string;               // 空格子背景色 (可选)
}
```

### 2. 默认皮肤配置表

商店默认内置多套特色主题皮肤：

1. **经典原版 (classic)**: 默认免费解锁，经典暖色调配色。
2. **霓虹赛博 (neon)**: 500 金币，炫酷高饱和霓虹暗色配色。
3. **暗黑科技 (dark)**: 1000 金币，极简深色高对比度配色。
4. **马卡龙 (macaron)**: 2000 金币，清新柔柔柔和马卡龙低饱和配色。

### 3. 购买与装备逻辑
* **持久化字段**：
  - `2048_unlocked_skins`: 已解锁皮肤 ID 列表 (例如 JSON 格式 `["classic", "neon"]`)。
  - `2048_equipped_skin`: 当前使用的皮肤 ID (默认 `'classic'`)。
* **交互流程**：
  - 未解锁 + 金币不足：显示“金币不足”及价格按钮（禁用/灰色提示）。
  - 未解锁 + 金币足够：点击“购买”，扣除对应金币，解锁该皮肤并自动装备。
  - 已解锁 + 未装备：显示“使用/装备”按钮，点击切换当前全局皮肤。
  - 已装备：显示“已使用”标记。

## 四、 UI 与交互设计

### 1. 主界面 UI 新增
* **金币显示组件 (Coin Display)**：位于界面顶部（得分/最高分旁），实时展示玩家当前金币数量（带金币图标/文本 `🪙 1250`）。
* **商店入口按钮 (Shop Button)**：主界面顶部或顶部操作栏增加“皮肤商店”按钮，点击打开商店弹窗。

### 2. 商店弹窗 UI (`ShopOverlay`)
* **弹窗遮罩与面板**：沿用项目现有 Graphics 动态绘制风格。
* **皮肤卡片列表**：列表展示各个皮肤的预览效果（缩略示例方块）、皮肤名称、价格与操作按钮。
* **金币实时更新**：商店内部同步显示当前总金币，购买皮肤后即时刷新余额与按钮状态。

## 五、 技术架构与代码修改方案 (Minimal Change)

根据项目 `AGENTS.md` 的规范，遵循**最小修改原则**：

### 1. 新增配置与服务层 (`SkinManager.ts` / `CoinManager.ts` 或集成扩展)
* 创建 `SkinConfig.ts`：放置皮肤配置文件及数据读写管理类（获取金币、增加金币、解锁皮肤、获取当前装备皮肤等）。

### 2. 改造 `BoardLogic.ts`
* 新增金币计算相关的方法或辅助计算公式（根据 `Difficulty` 获取金币转化率）。

### 3. 改造 `GameManager.ts`
* 在 `onLoad` / `start` 中加载当前金币和已装备皮肤。
* 根据当前装备皮肤动态计算 `TILE_COLORS` 方块颜色。
* 在得分更新 `updateScore` 时同步换算并增加金币，更新 UI 显示。
* 增加商店弹窗 (`ShopOverlay`) 的显示、关闭与列表渲染逻辑。

## 六、 验证与测试计划

1. **金币换算测试**：
   - 验证简单、中等、困难、噩梦模式下，得分后金币增加数量是否符合预期比例。
   - 重新开始/切换难度后，总金币数正常保存不丢失。
2. **商店购买与解锁测试**：
   - 金币不足时无法购买；金币足够时扣金币并解锁成功。
   - 刷新/重启游戏后，已解锁皮肤与装备皮肤状态正常保存。
3. **皮肤效果测试**：
   - 切换皮肤后，棋盘上的方块颜色立即更新为新皮肤配色。
